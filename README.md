# English with Yev — бот автопостинга

## Расписание (по умолчанию, московское время)

| Когда | Рубрика | Что внутри |
|---|---|---|
| ежедневно 09:00 | 📚 Word of the Day | слово, транскрипция, перевод, значение, 2 примера, коллокации |
| ежедневно 11:00 | 🚫 Mistake of the Day | типичная ошибка ❌ → правильно ✅ + объяснение |
| ежедневно 13:00 | 🗣 Phrase of the Day | фраза/идиома, пояснение, примеры |
| ежедневно 17:00 | 🧠 Quiz | викторина Telegram с правильным ответом и объяснением |
| ежедневно 20:00 | ☕️ Question of the Day | вопрос для ответа в комментариях + начало фразы |
| воскресенье 12:00 | 🏆 Weekly Test | серия викторин по словам недели + «пишите результат в комментариях» |
| среда 19:00 | 📣 Promo | анонс по кругу: справочник, Копилка учителя, Small Talk Buddy, конспекты Spotlight, разговорный клуб |

## 1. Создать бота
1. В Telegram откройте @BotFather → `/newbot` → придумайте имя → скопируйте **токен**.
2. Узнайте свой ID в @userinfobot — это **ADMIN_ID**.
3. Канал → Управление каналом → Администраторы → Добавить → найдите бота → право **«Публикация сообщений»**.

## 2. Залить на GitHub
Создайте новый репозиторий и загрузите файлы: `bot.py`, `content.json`, `requirements.txt`, `Procfile`, `README.md`.

## 3. Railway
1. New Project → Deploy from GitHub repo → выберите репозиторий.
2. Variables:
   - `BOT_TOKEN` — токен от BotFather
   - `CHANNEL_ID` — `@english_with_yev`
   - `ADMIN_ID` — ваш ID
   - `TZ_NAME` — `Europe/Moscow` (или `Asia/Ho_Chi_Minh`)
3. Start command (если Railway не подхватил Procfile): `python bot.py`

### Необязательные настройки
- Время: `TIME_WORD`, `TIME_MISTAKE`, `TIME_PHRASE`, `TIME_QUIZ`, `TIME_QUESTION`, `TIME_TEST`, `TIME_PROMO` — формат `09:00`. **Пустое значение выключает рубрику.**
- Дни: `DAYS_WORD`, `DAYS_MISTAKE`, … `DAYS_PROMO` — номера через запятую, `0` = воскресенье, `1` = понедельник … `6` = суббота. Например, `DAYS_MISTAKE=1,3,5` — ошибка дня только пн/ср/пт.
- `TEST_SIZE` — сколько последних слов в воскресном тесте (по умолчанию 7).
- `START_DATE`, `SIGNATURE`.

## 4. Проверка
Напишите боту в личку (типы: `word`, `mistake`, `phrase`, `quiz`, `question`, `test`, `promo`):
- `/start` — расписание и команды
- `/preview test` — посмотреть сегодняшний пост (себе)
- `/tomorrow mistake` — посмотреть завтрашний
- `/post promo` — опубликовать в канал прямо сейчас

## Как добавлять контент
Всё лежит в `content.json`: `words`, `phrases`, `quizzes`, `questions`, `mistakes`, `promos`.
Добавьте элементы по образцу, закоммитьте — Railway перезапустит бота.
Каждый список идёт по кругу независимо. Воскресный тест собирается автоматически из слов дня.

**Промо:** текст пишется с HTML-разметкой (`<b>жирный</b>`, `<i>курсив</i>`). Если заполнить `url` (и `button`), под постом появится кнопка-ссылка — например, на оплату справочника или бота «Копилки».

Ограничения Telegram для викторин: вопрос до 300 символов, вариант ответа до 100, объяснение до 200.
